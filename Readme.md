## Инструкция по сборке и запуску программы

### Требования
* JDK 25 (или выше)
* Apache Maven

### Сборка проекта
Для сборки проекта и скачивания всех необходимых зависимостей (Gson, Lombok) выполните в корневом каталоге команду:
```bash
mvn clean compile
```

### Запуск программы
Запустить главное приложение можно с помощью плагина Maven:
```bash
mvn exec:java -Dexec.mainClass="Main"
```
*Убедитесь, что файл `books.json` находится в корневой директории проекта рядом с файлом `pom.xml`.*
